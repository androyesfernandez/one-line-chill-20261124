A single sentence of horror for the "One Line, One Chill" competition. In a
hospice room, a nurse marks the narrator's father deceased at 3:12 a.m. — and
one minute later, at 3:13, the call button beside his bed rings. A voice asks
for the narrator by name, in the father's own voice, coming from the speaker
beside his body. The scare is the one-minute gap and the voice that should
not be able to speak.

## How to run

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (196 characters, no trailing
newline) and verifies the file on disk is byte-identical to the line.
